# Работа агента с этим репозиторием

Если пользователь поручил установить сервис обмена OCR-задачами по ссылке на этот репозиторий, прочитай `INSTALL_FOR_AGENTS.md` и выполни установку. Предварительно устанавливать скилл в Codex или просить пользователя запускать команды вручную не требуется: готовый пакет уже находится в `skills/ocr-kanban-setup`.

Сохрани исходную папку проекта пользователя **до** клонирования репозитория: каталог установщика не является рабочим проектом заказчика. **Сам запроси у пользователя путь к выданному файлу ключа нужной роли**, если он ещё не передан. Проси путь, а не содержимое токена в чате. Не требуй предварительно перенести файл в специальный каталог: используй исходное расположение. Сам передай путь установщику, который создаст служебные папки и сохранит рабочий ключ в локальном `client.json`; проверь результат без вывода токена. Исходный файл не удаляй. Папку проекта и клиент уточни только при отсутствии достоверных сведений. Не задавай повторные вопросы, если ответ уже известен. Используй обёртку `install.ps1` / `install.sh` с полными аргументами, чтобы не оставить интерактивный установщик ждать невидимый ввод.

Запрос пользователя на установку охватывает навык, мост, помощник и пользовательский автозапуск. Не запрашивай отдельное подтверждение каждого штатного шага. Если среда требует разрешение, соблюдай её правила и объясни конкретную блокировку. Не отключай песочницу, политики организации или проверку отпечатков.

Файлы подключения и токены не публикуй, не добавляй в Git и не выводи в чат или журнал. В команде передавай только путь к файлу. `connection.example.json` — пример без действующего ключа. Не выбирай роль по названию файла: сервер проверяет ключ. Ключ администратора для установки клиента не подходит.

macOS и Windows ARM64 пока не имеют подтверждённых живым тестом адаптеров. Сразу объясни этот предел, если устанавливаешь на такой платформе; установка файлов не доказывает доставку сообщений. Не обходи это ограничение подстановкой Windows-хешей, сменой `verified` или автоматическим утверждением нового профиля.

Не сбрасывай уже работающий мост и не создавай вторую установку поверх другой роли. При обнаружении старого навыка или чужой привязки сохрани данные и сообщи, какая миграция нужна. После установки проверь фактический статус и диагностику; не отвечай «всё работает» по одному коду выхода установщика. Не создавай реальную задачу и не утверждай планы от имени разработчика ради проверки.

При запросе на чтение, аудит или изменение репозитория не запускай установку без соответствующего поручения пользователя. Серверные операции, публикация обновлений и изменение проекта OCR не являются частью обычной установки клиента.
